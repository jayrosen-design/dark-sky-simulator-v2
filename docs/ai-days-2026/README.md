# UF AI Days 2026: Restoring the Milky Way

Poster and plenary talk for UF AI Research, Teaching, and Learning Day (Tuesday, October 27, 2026, 2:40–2:55 PM,
Reitz Union Grand Ballroom), presenting this simulator.

| File | What it is |
| --- | --- |
| `Dark Sky Simulator v2 - AI Days poster 48x36 (final for print).pdf` | The 48 × 36 in poster, print-ready (fonts embedded). |
| `Dark Sky Simulator v2 - AI Days poster 48x36 (final for print).pptx` | The poster as editable PowerPoint (needs the Aptos font). |
| `Dark Sky Simulator v2 - UF AI Days 2026.pptx` | The 15-minute talk: 27 slides plus 4 hidden backups, with speaker notes. Ten slides play short, silent screen recordings of the simulator that start with the slide and loop. |
| `Dark Sky Simulator v2 - UF AI Days 2026.pdf` | The talk as a PDF, without notes; video slides show a still frame. |

Every figure is a planning estimate from this repository's model, not a measurement: skyglow values are uncalibrated
projections (see the README's deviations and `docs/adr/`). Costs come from the simulator's cost engine at each
utility's published rates; the observatory shortlist uses the siting rules in ADR 0014.
